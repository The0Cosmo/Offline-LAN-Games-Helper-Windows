# Security Policy

## Supported Versions

This project is currently in early development.

| Version | Supported |
| ------- | --------- |
| v0.1.x  | Yes       |

## Reporting a Vulnerability

If you discover a security vulnerability in **Offline LAN Games Helper for Windows**, please do not open a public issue.

Instead, report it privately using GitHub Private Vulnerability Reporting if available.

When reporting a vulnerability, please include:

- A clear description of the issue
- Steps to reproduce it
- The affected version
- Your Windows version
- Any possible impact
- Suggested fix, if known

I will review valid security reports as soon as possible.

## Security Notes

This project is designed for local network/LAN use.

Please be careful when using it on public or untrusted networks. Only run the tool on networks you trust.
